# 10. 저장소와 확장 경계

공통 의미·권한·판정·원장은 platform, 장비별 native 의미·Host·실행기·UI·적용 패키지는 solutions, 설계·규범·증거 출처는 rx_docs가 소유한다. 상세 표는 [아키텍처](05_software_architecture.md)를 따른다.

새 장비는 profile과 adapter, 새 서비스는 작업 흐름과 완료 조건, 새 운영 영역은 신뢰·권한·인계 계약의 영향부터 검토한다. 장비 이름을 코어에 하드코딩하거나 모든 배포에 한 제조사의 stack을 강제하지 않는다.

두 제품 이미지와 저장소 수는 동일한 프로세스 수를 뜻하지 않는다. 분산 배치는 장기 목표이며 현재 단일 Runtime 계약으로 검증됐다고 주장하지 않는다.

이 주제의 이전 산업 초안은 [고정 원문](https://github.com/jack0682/rx_docs/blob/6111a7d1dcf33052f38c3e67c6585aec2b44df3c/docs/10_structure_proposal.md)에 보존한다.
