# 17. 운영 영역과 현재 Cell의 경계

현재 `Cell`은 위험·제어·물품 인계가 결합된 운영 범위다. 로봇 한 대나 컨테이너 하나와 동일하지 않다. 현재 규범은 같은 주 컴퓨터의 단일 권위 Runtime을 전제로 한다.

도시·마을·건물의 운영 주체 사이 연결에는 추가 신뢰·권한·책임 인계가 필요하다. Cell 이름을 바꾸거나 현재 monotonic clock·단일 writer를 그대로 복제하는 것만으로 분산 계약이 성립하지 않는다.

후속 대조는 영역별 실행 권한, 공유 자원 소유, 물품 인계, 단절 때 허용 행동, 재연결 뒤 관측·결과 조정으로 나눈다. 이 항목은 설계 의제이며 현재 구현 완료가 아니다.
