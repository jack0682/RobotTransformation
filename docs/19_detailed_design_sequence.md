# 19. 다음 설계 단위

[로드맵](00_design_roadmap.md)의 작은 인계 사례를 다음 설계 단위로 제안한다. 시작·완료·인계·거부·유실·미결을 먼저 정의하고 기존 계약과 대조한다.

산출물은 사례 카드, 참여자·물품·공유 자원의 식별, 권한과 관측 원천, 단계별 후조건, 장애 trace, 현재 계약의 재사용/추가 항목, 검증 명령과 완료 기준이다.

실제 연동에서는 [미결 목록](implementation/critical_open_items.md)의 제어권·관측·복구 문제를 해당 장비 범위로 확인한다. 기존 산업 납품의 모든 기능·현장 입력을 비산업 설계의 선행 작업으로 확장하지 않는다.

이 주제의 이전 산업 초안은 [고정 원문](https://github.com/jack0682/rx_docs/blob/6111a7d1dcf33052f38c3e67c6585aec2b44df3c/docs/19_detailed_design_sequence.md)에 보존한다.
