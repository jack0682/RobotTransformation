# 적용 사례의 검증 경로

선택한 서비스의 시작·최종 완료·참여자·물품·자원·개입을 먼저 정의한다. 다음 근거를 해당 범위에서 쌓는다.

1. 현재 계약과 profile을 대조하고 빠진 의미·관측·권한을 기록한다.
2. 모의 구성에서 정상·유실·중복·경합·재시작·저장 실패를 검증한다.
3. 실제 장비 하나씩 source·제어권·관측·지지·lifecycle을 확인한다.
4. 설치 envelope·보호 책임·개입·복구 절차의 근거를 검토한다.
5. 최종 완료·대기·미결·복구·연결 비용을 지정 조건에서 측정한다.

단위·CI·모의 시험은 그 층의 증거이며 실물 qualification을 대신하지 않는다. 범위를 줄여 시험했다면 축소 범위와 기존 미결을 함께 남긴다. 이전 모의 인수는 [인계](draft_handoff.md), 현재 미결은 [목록](critical_open_items.md)을 따른다.
