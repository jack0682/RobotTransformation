# 구현 상태와 검증 기록

2026-10-01의 [현황 기반 세부 개발 계획](framework_delivery_plan.md)은 최신 develop, 미커밋 작업,
공개 설치본을 구분하고 WF01–WF17/RF01–RF14/PG07의 구현 책임·의존성·수락 시험을 연결한다.
계획 문서의 항목은 구현 완료 증거가 아니며 아래 과거 인계 기록과 구별한다.

이 디렉토리는 현재 코드의 출발점과 남은 한계를 안내한다. [인계와 검증 경계](draft_handoff.md), [핵심 미결](critical_open_items.md), [아키텍처](architecture.md), [현재 요구 추적](requirements.md)을 순서대로 읽는다.

기존 초안 v0.1의 검증은 2026-09-13 당시 commit·이미지·모의 시나리오에 해당한다. 현재 제조사 중립화와 저장소 정비의 검사는 새 결과로 기록한다. 과거 단계 번호·통과 수·이미지 digest를 바꿔 새 구성의 증거로 만들지 않는다.

상세 phase 기록·소스 스냅샷·원래 요구/감사표는 [이전 기록](../../references/README.md)에 보존한다. 새로운 서비스·다중 운영 영역·실물 운전은 아직 별도 검증 대상이다.
