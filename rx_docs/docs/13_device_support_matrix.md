# 13. 장비 지원과 연동 정책

RX는 개인 프로젝트이며 공통 계약은 제조사 중립으로 유지한다. 2026-09-25 G5 사용자 추가 지시에 따라 ROBOTIS 다섯 프로젝트가 기본 전체 개발 번들의 선정 대상이다. 이는 이전 기본 포함 의무 부재 정책의 명시적 변경이며, 제공 능력·실물 검증·운영 권한을 제조사 이름으로 부여한다는 뜻은 아니다. 선정 버전·의존성·미완료 통합은 [G5.1 기록](40_strict_wire_and_clients.md)과 [첫 DYNAMIXEL 모의 어댑터](41_dynamixel_ping_adapter.md)에 구분한다.

## 지원 선언의 단위

지원은 `제조사/모델/하드웨어 revision × firmware × controller/driver × mode × OS/CPU × binding/profile × 작업 범위`의 조합으로 기록한다. 동일 제품군 이름으로 조합을 합치지 않는다. 실제 장비 식별에 필요한 제조사·모델 metadata는 허용되지만 공통 코어의 분기·제품 정체성이 되어서는 안 된다.

| 상태 | 필요한 근거 | 의미 |
|---|---|---|
| 계획 | 요구·native interface·담당 범위 | 구현이나 실행 허가 없음 |
| 구성 가능 | 버전 고정 source·license·빌드·설치 | 실물 지원 완료 아님 |
| 모의 검증 | 명시 fixture와 commit의 계약·장애 시험 | 해당 모의 환경에만 적용 |
| 실물 검증 | 설치 개체·교정·제어권·관측·lifecycle·복구 시험 | 기록된 환경과 작업 범위만 지원 |
| 운영 승인 | 현장 envelope·보호 책임·절차·qualification | 그 설치의 유효 조건 안에서만 실행 허용 |

현재 새 제조사 중립 구성의 실물 지원을 승인한 장비 목록은 없다. 과거 이미지의 의존성 포함·빌드 결과는 [이전 기록](../references/README.md)에 남으며 새 구성의 지원 완료가 아니다.

## 연동이 제공할 계약

- 요청·native ID·결과 조회의 상관관계, 완료·중단·결과 불명의 의미.
- 제어권의 실제 소유·세대·직접 native client와의 배타성.
- 원본 관측의 시각·순번·출처, 재부팅과 오래된 cache 검출 범위.
- 공유 controller·버스·공간·물품의 자원과 인계 조건.
- 기동·모드·정상 종료·강제 종료가 토크·지지·잔류 명령에 미치는 효과.
- source commit·전이 의존성·license·플랫폼 제약과 실제 시험 증거.

빠진 근거를 `READY=true`로 채우지 않는다. 공통 요구는 [binding/admission 규범](contracts/v1.0/04_binding_and_admission.md)을 따른다. SDK와 driver를 제거하거나 바꿀 때에도 제삼자의 저작권·라이선스·출처는 보존한다.
