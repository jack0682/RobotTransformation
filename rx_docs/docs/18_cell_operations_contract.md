# 18. 셀 운영 계약 안내

[셀 운영 계약 v1.0](cell_operations/v1.0/README.md)은 운전 범위·조건·시작 의도·1회 작업 허가·개입·복구·변경 후 재검토를 정의한다. 기초 작업 의미는 [공통 계약 v1.0](contracts/v1.0/README.md)을 재사용한다.

실제 설치에 필수 입력과 근거가 없으면 NOT_COMMISSIONED를 유지한다. 기존 작업 성공과 현재 조건, 결과 확정과 자원 인계, normal transient 회복과 권한 철회 후 새 시작을 구별한다.

이번 제조사 중립화의 문서 변경과 manifest는 [개정 기록](cell_operations/v1.0/revision_2026-09-14.md)을 따른다. wire 의미와 실제 검증 상태를 문서 정비만으로 승격하지 않는다.

이 주제의 이전 산업 초안은 [고정 원문](https://github.com/jack0682/rx_docs/blob/6111a7d1dcf33052f38c3e67c6585aec2b44df3c/docs/18_cell_operations_contract.md)에 보존한다.
