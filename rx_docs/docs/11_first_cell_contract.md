# 11. 첫 적용 사례와 계약 대조

첫 비산업 검증 후보는 `역할 A의 물품 전달 → 인계 지점 확인 → 역할 B의 인수 → 목적지 전달`이다. 장비·장소·최종 수령 조건은 미정이다.

각 단계에서 시작 의도·물품 identity·자원·실행 주체·권한·완료 관측·취소·불명·재시작을 정의한다. 인계 도중 응답 유실, 다음 참여자의 거부, 물품 보유 관측 충돌을 반례로 다룬다.

이전 첫 산업 셀의 미확정 상태는 NOT_COMMISSIONED로 유지하고 [고정 원문](../references/README.md)에 보존한다. 현재 검증 후보를 그 셀의 장비나 신호에 종속시키지 않는다. 규범은 [공통 계약](contracts/v1.0/README.md)과 [셀 운영 계약](cell_operations/v1.0/README.md)을 따른다.

이 주제의 이전 산업 초안은 [고정 원문](https://github.com/jack0682/rx_docs/blob/6111a7d1dcf33052f38c3e67c6585aec2b44df3c/docs/11_first_cell_contract.md)에 보존한다.
