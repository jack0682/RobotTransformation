## 계획과의 차이

- Phase 2 항목 세 개(재시작 인수 A안, 중단 없는 writer, 유지 Host rebind)를 Phase 1보다 먼저 진행했다. 사용자가 개발 착수를 요구했고, A안 검증 중 rebind 공백이 드러나 이어서 처리했다. Phase 1(코어 헌장·경계·봉합선)은 다음 순서다.
- 비교표의 첫 판정에서 rebind를 재수용과 같은 것으로 보고 폐기했다가, 실제 이미지 실행으로 오류를 확인하고 정정했다([기록](../../references/p_restart_adoption_2026-09-29/README.md)).
