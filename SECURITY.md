# Security policy

RobotTransformation is under development. G0 contains governance only; no product release or physical operating readiness is claimed. Security review and CI do not constitute functional-safety certification or permission to operate equipment.

Report authority bypass, secret exposure, replay, journal-integrity, or recovery-boundary vulnerabilities through [GitHub private vulnerability reporting](https://github.com/jack0682/RobotTransformation/security/advisories/new) when that repository feature is enabled. If the private route is unavailable, contact the maintainer through an existing private channel; do not publish sensitive details in an issue while waiting.

Include the affected commit/artifact, environment, minimal reproduction, expected impact, and evidence limits. Simulation evidence is sufficient. Do not test physical equipment or systems belonging to others without explicit authorization.

Fixes follow reviewed, signed PRs and applicable verification. The operator separately determines procedures for any deployed system. No long-term support or response-time commitment is made for historical snapshots.
